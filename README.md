# 📱 Programação para Dispositivos Móveis — FATEC Jahu

Repositório com os projetos desenvolvidos em sala de aula na disciplina **Programação para Dispositivos Móveis**, ministrada na [FATEC Jahu](https://fatecjahu.edu.br/).

Cada pasta representa um projeto completo desenvolvido durante as aulas, utilizando **.NET MAUI** e **C#** para criar aplicações multiplataforma (Android e iOS).

| Projeto | Descrição |

---

## 🛠️ Tecnologias Utilizadas

- [**.NET MAUI**](https://learn.microsoft.com/pt-br/dotnet/maui/) — framework multiplataforma para apps Android, iOS, Windows e macOS
- **C#** — linguagem principal de desenvolvimento
- **XAML** — markup para criação das interfaces

---

## ⚙️ Pré-requisitos

Para rodar os projetos localmente, você precisa ter instalado:

- [Visual Studio 2022](https://visualstudio.microsoft.com/) com a carga de trabalho **Desenvolvimento Móvel com .NET**
- [.NET 8 SDK](https://dotnet.microsoft.com/download) ou superior
- Emulador Android (via Android Studio) ou dispositivo físico

---

## 🚀 Como executar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/vnicus/dispositivos-moveis.git
   cd dispositivos-moveis
   ```

2. **Abra o projeto desejado no Visual Studio:**
   - Vá em `Arquivo > Abrir > Projeto/Solução`
   - Navegue até a pasta do projeto e abra o arquivo `.sln`
